# Steering: Naming Conventions (JavaScript/TypeScript)

Loads when `.js`, `.mjs`, `.cjs`, `.ts`, `.tsx`, or `.jsx` files are in use. Use it to keep JavaScript and TypeScript names consistent.

[View example steering: naming-conventions-javascript.md](../../examples/steering/naming-conventions-javascript.md)

What it covers:

- **Core styles:** `camelCase` for variables and functions, `PascalCase` for classes, types, and React components, `UPPER_SNAKE_CASE` for global constants.
- **Private members:** `#name` in new code, leading underscore only where the codebase already uses it.
- **Handlers, collections, and file names:** `handleClick` functions with `onClick` props, plural collection names, and file names that follow the project's majority style.

Copy it to `.kiro/steering/` in your project. Use it together with [Naming Conventions (Common)](./naming-conventions-common.md).
