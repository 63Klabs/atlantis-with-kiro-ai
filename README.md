# Atlantis with Kiro AI

This repository provides Kiro IDE configuration for the [63Klabs Atlantis DevOps Platform](https://atlantis.63klabs.net) for serverless deployments on AWS.

## What's included:

- **Atlantis MCP server** – Automates template discovery, validation, and documentation lookups directly in your IDE
- **Skills** – Reusable AI instructions for common tasks like package auditing, GitHub issue sync, and naming validation
- **Steering documents** – Context-aware project guidelines for Atlantis-specific conventions (naming, security, architecture)
- **Agents.md** – Single-file AI context that enforces platform guardrails across your team

Use the [63Klabs Atlantis MCP server](https://mcp.atlantis.63klabs.net) to keep these resources up to date, or clone examples directly into your project.
